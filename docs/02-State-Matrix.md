# 02 · 全页面状态矩阵（默认 / 加载 / 空 / 失败 / 弱网 / 极限边界）

> 对应岗位 JD 面试 5 步第 3 步：**「空和失败怎么处理」**。

| 页面 / 模块 | 默认态 (Default) | 加载与弱网态 (Loading / Slow) | 空态 (Empty) | 失败态 (Error) | 离线态 (Offline) | 极限与防错边界 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **今日伴读 (`HomePage`)** | 孩子切换胶囊、伴读笔状态胶囊、今日推荐主卡、7日足迹、清单 | 1:1 结构骨架屏 (`HomeSkeleton`)；超过 `800ms` 顶部出现暖色提示「网络有点慢，正在努力加载…」 | 插画 + 「今天还没有安排伴读篇目」+ 主按钮「去蒙学馆挑一篇」 | 友好错误说明 + 错误码 `ERR_NETWORK_TIMEOUT` + 「重新加载」按钮 | 顶部展示缓存提示条 (`OfflineBanner`)，正常浏览已缓存篇目 | 标题超长单行/双行截断 (`line-clamp-2`)；切换孩子与设备按钮带请求锁防连点 |
| **逐句领读 (`ReaderPage`)** | 楷体大字 + 拼音开关 + 语速 `0.75x/1.0x` + 重点字下划线 + 底部单手操作坞 | 卡片级骨架屏 (`ReaderSkeleton`) + 慢网提示 | 篇目被下架或不存在时提示「未找到这篇蒙学内容」+ 「返回上一页」 | 错误提示 + 一键重试，不破坏路由栈 | 正常离线朗读（本地种子/缓存），提交打卡时提示离线并保留进度 | 中途退出弹窗保存 `lineIndex`；打卡接口失败时保留当前完成页并展示内联「重试打卡」按钮；同天重复打卡幂等保护 |
| **蒙学馆 (`LibraryPage`)** | 吸顶搜索框 + 分类胶囊 + 年龄筛选 + 篇目卡片 + 「设为今日」 | 列表卡片骨架屏 (`LibrarySkeleton`) | 筛选无结果时展示「没有找到匹配的篇目」+ 一键「清空筛选条件」 | 错误态 + 重试按钮；「设为今日」采用乐观更新，失败自动回滚并 Toast 提示 | 离线可筛选已缓存篇目；「设为今日」变更提示联网后同步 | 输入框 `280ms` 防抖 + `AbortController` 取消过期请求，杜绝“后发先至”串行覆盖 |
| **伴学档案 (`ProfilePage`)** | 孩子 KPI（连续天数/累计分钟/已读篇目）、硬件管理、后台入口 | 复用结构化骨架屏 | 档案为空时提供「恢复默认示例」按钮 | 错误态 + 重试按钮 | 展示缓存数据；设备模拟操作给出明确提示 | 「重置演示数据」一键清空并恢复初始状态，方便面试反复演示冷启动 |
| **PC 管理后台 (`AdminPage`)** | 4 个 KPI 卡片 + 筛选栏 + 篇目表格 + 侧滑编辑抽屉 | 表格加载占位提示 | 筛选无数据时展示「暂无符合条件的篇目」 | 内联重试按钮 + 表单校验提示（标题/适龄/正文必填） | 本地持久化实时同步至家长端 | 拼音按字符自动对齐标点，新建/下架后切回手机端即时生效 |
