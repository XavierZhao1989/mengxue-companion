# 03 · 视觉排版与设计系统规范（Design System）

> 色彩对比度、字号阶梯、8pt 空间系统与多端安全区适配规范。工程实现见 [tokens.css](../src/styles/tokens.css)，跨工具 Token 文件见 [design-tokens.json](./design-tokens.json)。

## 1. 色彩系统（为什么选宣纸暖白，而不是纯白 + 高饱和蓝）

儿童启蒙场景多发生在**傍晚及睡前暗光环境**，大面积 `#FFFFFF` + 高饱和科技蓝对家长和孩子的眼睛刺激强：
- **画布底色 `--bg-canvas: #FAF7F2`**：微暖宣纸色调，降低夜间刺眼度，同时与纯白内容卡片 `--bg-surface: #FFFFFF` 自然拉开层级；
- **主文字 `--text-primary: #2C2621`**：暖深墨色，在宣纸底上对比度超过 **12:1**（远超 WCAG AA 4.5:1），兼顾阅读清晰与东方绘本温润感；
- **主强调 `--brand-primary: #C85A32`**：朱砂暖橙，专门用于核心行动按钮与重点生字引导，一眼明确视觉焦点；
- **正向反馈 `--brand-jade: #2F7D63`**：松烟青绿，用于连续打卡、蓝牙已连接、上架成功等状态。

## 2. 字号阶梯与信息层级

| 层级 Token | 字号 / 行高 | 字重 | 使用场景 |
| :--- | :--- | :--- | :--- |
| `--text-primer` | `28px / 46px` | Regular (楷体/宋体优先) | 逐句领读核心古诗文正文，留足上方拼音空间 |
| `--text-display` | `24px / 32px` | 700 | 首页今日伴读篇目标题、管理后台主标题 |
| `--text-h1` | `20px / 28px` | 700 | 页面导航栏标题、弹窗标题 |
| `--text-h2` | `17px / 24px` | 600 | 列表卡片标题、分栏小标题 |
| `--text-body` | `15px / 24px` | 400 | 家长白话解释、简介正文 |
| `--text-caption` | `12px / 18px` | 400–500 | 拼音注音、耗时、分类标签、辅助说明 |

## 3. 8pt 空间系统、热区与多端安全区适配

1. **8pt 网格节奏**：页面外边距统一 `16px`，主卡片内边距 `20px–24px`，次级卡片 `16px`，元素间距严格落在 `4 / 8 / 12 / 16 / 20 / 24px` 阶梯上（可在右侧演示台开启 **「设计标注透视层」** 直观查看）。
2. **拇指热区 ≥ 44×44pt**：返回按钮、TabBar 按钮、底部抽屉关闭按钮全部应用 `.touch-target`（`min-width: 44px; min-height: 44px`）；首页主按钮高度 `52px`，领读主播放圆钮 `54×54px`，均落在单手握持拇指黄金区间。
3. **小屏（375×667）与刘海/安全区适配**：
   - 底部固定栏与抽屉均使用 `calc(12px + var(--safe-bottom))`，真机回退 `env(safe-area-inset-bottom, 0px)`，桌面模拟器支持 `iPhone 15 Pro (48/24px)`、`iPhone SE (20/0px)` 与 `微信小程序 (胶囊避让 96px)` 一键切换验证；
   - 移动端容器使用 `100dvh` 替代 `100vh`，避免 iOS Safari 工具栏遮挡底部操作坞。
4. **微交互与无障碍**：
   - 所有可点击控件使用 `.pressable`（`active` 态 `scale(0.97)` 140ms 物理按压感）；
   - 全局支持 `@media (prefers-reduced-motion: reduce)`，减弱动画以照顾前庭敏感用户。
